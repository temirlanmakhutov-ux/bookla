# Bookla — MVP (сайт + PWA)

Онлайн-запись куда угодно на Северном Кипре. Next.js 16 + Prisma + SQLite (локально) → Postgres (продакшен).

## Запуск на своём компьютере

```bash
cd web
npm install
npm run db:reset     # создаёт базу prisma/dev.db и заливает 19 вымышленных бизнесов
npm run dev          # http://localhost:3000
```

Демо-входы (только локально): `demo@bookla.local` — владелец «Limon Kuaför», `admin@bookla.local` — админ.
Пароль для обоих — `DEMO_PASSWORD` в файле `web/.env`.

## Что где

| Адрес | Что это |
|---|---|
| `/` | каталог: поиск, категории, лучшие места |
| `/search?cat=&city=&q=` | результаты поиска |
| `/b/<slug>` | страница бизнеса — **ссылка, которую бизнес ставит в Instagram / Google Maps** |
| `/booking/<token>` | страница записи клиента: детали, календарь, отмена |
| `/biz` | лендинг для бизнеса, тарифы |
| `/biz/signup`, `/biz/login` | регистрация (30 дней бесплатно) и вход владельца |
| `/dashboard/*` | кабинет: записи по дням, услуги, мастера, часы, профиль + QR, подписка |
| `/admin` | админ: продление подписок, скрыть/показать бизнес, очередь WhatsApp |

## Как устроено

- **Язык** — TR / EN / RU, по cookie или языку браузера (`src/i18n`).
- **Время** — всё в часовом поясе Северного Кипра (`Asia/Famagusta`); дата `YYYY-MM-DD` + минуты от полуночи (`src/lib/time.ts`).
- **Свободное время** — `src/lib/availability.ts`: часы работы × длительность услуги × занятость мастеров.
  Если мастеров нет (ресторан, прокат, мойка) — считается по «количеству мест» (`capacity`).
- **Запись** — `src/lib/booking.ts`: перепроверка слота в транзакции (Serializable), двойная запись невозможна.
- **Клиенты без аккаунтов** — имя + телефон; управление записью по секретной ссылке.
- **Подписка — единственная модель дохода**: 30 дней триал → Соло 390 ₺ / Салон 890 ₺ в месяц (`src/lib/plans.ts`).
  Пока подписка не активна, бизнес скрыт из каталога и онлайн-запись выключена. Оплата пока вручную: админ продлевает в `/admin`.
- **WhatsApp** — `src/lib/notify.ts`: все сообщения пишутся в таблицу `Notification`. Без ключей WhatsApp Cloud API
  они сохраняются со статусом `skipped`; в кабинете есть кнопки «написать клиенту» через wa.me — работают уже сейчас и бесплатно.

## Боевой сайт

- Адрес: **https://bookla-rho.vercel.app** — Vercel, команда **ACME** (аккаунт `veqirosupport-2771`), проект `bookla`, регион `fra1`.
- База: **Neon Postgres** `bookla-db` (бесплатный тариф, Франкфурт), подключена через Vercel Marketplace —
  переменные `DATABASE_URL` / `DATABASE_URL_UNPOOLED` проставлены автоматически.
- Переменные в Vercel (Production): `ADMIN_EMAILS`, `CRON_SECRET`, `WHATSAPP_API_VERSION`. Адрес сайта для ссылок берётся
  из `VERCEL_PROJECT_PRODUCTION_URL`; после подключения своего домена можно задать `NEXT_PUBLIC_BASE_URL`.
- Выкладка новой версии: `cd web && npx vercel@latest deploy --prod`. Сборка (`npm run vercel-build`) сама применяет
  миграции из `prisma/migrations` к боевой базе.
- Локально по-прежнему SQLite: `npm run dev` генерирует `prisma/dev.sqlite.prisma` из `schema.prisma`.
- Новая миграция после изменения `schema.prisma`: создать ветку базы в Neon, указать её в `DATABASE_URL`/`DATABASE_URL_UNPOOLED`
  и выполнить `npx prisma migrate dev --name <что-изменилось>`; затем выложить.

## Что осталось до полноценного запуска

1. **Тариф Vercel**: Hobby — только для некоммерческих проектов; с первыми платными бизнесами перейти на Pro.
2. **Свой домен** (например, bookla.app / bookla.cy) — добавить в Vercel → Settings → Domains.
3. **WhatsApp Cloud API** — аккаунт Meta Business, номер, шаблоны сообщений (подтверждение, отмена, напоминание),
   потом заменить `text` на `template` в `notify.ts`. SMS через Twilio в KKTC не доставляются (см. `../docs/рынок.md`).
4. **Напоминания за 2 часа** — `/api/cron/reminders` готов; на Hobby Vercel Cron работает раз в сутки, поэтому вызывать его
   раз в 15 минут внешним планировщиком (например, cron-job.org) с заголовком `Authorization: Bearer <CRON_SECRET>` или перейти на Pro.
5. **Оплата подписки** — пока перевод/наличные + продление в `/admin`; онлайн-оплату подключить, когда будет ясно, какой шлюз работает с компанией в KKTC.
6. Ограничение частоты запросов на вход и запись, политика конфиденциальности (закон KKTC № 89/2007).
